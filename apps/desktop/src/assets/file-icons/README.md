# Symbols file icons

These SVGs and `file-icons.json` are copied from
[`miguelsolorio/vscode-symbols`](https://github.com/miguelsolorio/vscode-symbols)
at commit `296ef1b62287fb2315cb5651e552e09e8c8e1de8`.

NeverWrite bundles the assets at build time and uses the matching VS Code
file-icon theme manifest to resolve filenames, extensions, languages, MIME
types, and folder names. The upstream MIT license is retained in
`LICENSE.symbols`.
